Set up Kai

Flash a Stick, give it Wi-Fi and pair it with your relay. It all happens over USB, in this browser.

Before you start

  • An M5StickS3 and a USB-C cable that carries data.
  • A desktop browser with Web Serial: Chrome or Edge.
  • A Kai relay already running on your home network. The Stick finds it by itself.

1Flash and connect to Wi-Fi

Plug the Stick in, then press Install and pick its port.

This browser can't talk to USB devices. Open this page in desktop Chrome or Edge. Flashing only works over HTTPS. Open this page from its https:// address.

No firmware found next to this page. Open the published page, zbruceli.github.io/kai, rather than a copy of the file.

  • New Stick: choose erase when asked. Updating: don't erase, and the Stick keeps its Wi-Fi and pairing.
  • After flashing, enter your Wi-Fi network and password. They go over the cable to the Stick, which saves them only once it has joined that network.
  • No port in the list? Hold the side button for about 2 seconds, until the green light blinks (download mode), and try again.

2Pair it with your relay

Once on Wi-Fi, the Stick finds the relay and shows a 6-digit code. On the relay, run:

cd ~/kai/relay && uv run kai-approve 123456

with the code from the Stick. If the relay shows the same code, it accepts the Stick. Then press the front button on the Stick to keep the key.

Codes that don't match mean something on the network is in between: press the side button to cancel. Nothing secret crosses the network: the Stick and relay each work out the same key, and the code proves they did. The code lasts 5 minutes; to skip typing it, run uv run kai-pair --open 5 first and the next Stick that asks is accepted.

That's it: hold the front button and talk.

3Check or adjust the Stick (optional)

Close the install window first: only one page can use the port at a time.

Relay address

Leave it empty to let the Stick find the relay on the network. Set one when the relay is somewhere discovery doesn't reach, like another subnet.

Pair again

Forget this Stick's key, for a new relay or after kai-revoke. It shows a new code.

This page has no server: it only talks to the Stick over USB. The firmware holds no passwords or keys; those stay on your Stick. Source on GitHub (MIT).
