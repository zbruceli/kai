Set up Kai

Install Kai on a Stick, give it Wi-Fi and pair it with your relay. It all happens over USB, in this browser.

Before you start

  • An M5StickS3 and a USB-C cable that carries data.
  • A desktop browser with Web Serial: Chrome or Edge.
  • A Kai relay already running on your home network. The Stick finds it by itself.

1Your Stick

Plug the Stick in, then connect to it. You can then install or update Kai, set its Wi-Fi, or watch its logs.

No firmware found next to this page. Open the published page, zbruceli.github.io/kai, rather than a copy of the file.

This browser can't talk to USB devices. Open this page over HTTPS in desktop Chrome or Edge.

  • Pick USB JTAG/serial debug unit in the list.
  • No port in the list? Hold the side button for about 2 seconds, until the green light blinks (download mode), and connect again.
  • Port busy? Close other tabs or apps using the Stick, like another copy of this page or a serial monitor.

Wi-Fi

The password goes over the cable to the Stick only. It saves the network once it has joined it, so a typo can't cut off Wi-Fi that works.

2Pair it with your relay

    
Once on Wi-Fi, the Stick finds the relay and shows a 6-digit code. On the relay, run:

    
cd ~/kai/relay && uv run kai-approve 123456

    
with the code from the Stick. If the relay shows the same code, it accepts the Stick. Then
      press the front button on the Stick to keep the key.

    
Codes that don't match mean something on the network is in between: press the side button
      to cancel. Nothing secret crosses the network: the Stick and relay each work out the same key, and the
      code proves they did. The code lasts 5 minutes; to skip typing it, run uv run kai-pair --open 5
      first and the next Stick that asks is accepted.

    
That's it: hold the front button and talk.
